Войти в админку

Используйте свой GitHub-токен с правом записи в wwoland/topmusic-site.

Где взять токен?

Каждый редактор создаёт свой токен один раз и входит с ним до окончания срока действия.

  1. Откройте создание токена GitHub (classic).
  2. Отметьте только право public_repo и создайте токен.
  3. Скопируйте его и вставьте в поле выше.
Создать токен на GitHub ↗

Владелец репозитория может использовать fine-grained токен с Contents: read and write. Токен не сохраняется в браузере.
